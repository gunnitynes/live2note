Live → Note

Drop a rack or a Live Set here and get presets your phone can open. Drift synths and Drum Racks come over with every setting, macro mappings included. Anything Note can't play gets a plain explanation of what to change.

Drop a rack (.adg) or a Live project folder

Using drum samples? In Live choose File → Collect All and Save, then drop the whole project folder (the one with the Samples folder inside), not just the .als file.

Example results

Getting it onto your phone

  1. Download the .ablpresetbundle file.
  2. On a Mac: right-click it, choose Share → AirDrop, pick your phone, then choose Ableton Note. On Windows: put it in iCloud Drive, Dropbox or Google Drive.
  3. From a cloud folder: open the Files app, tap the file, then Share → Ableton Note.
  4. In Note it appears under User Library → Presets.

What Note can play

Synth

One Drift. Note plays up to 8 voices, so anything above that is set to 8. Wavetable, Operator, Meld, plug-ins and Max for Live don't run on the phone.

Drums

A Drum Rack of up to 16 pads, each using Drum Sampler (right-click the rack → Replace Simplers with Drum Sampler). One return chain allowed.

Effects

Two slots after the instrument: Reverb, Delay, Saturator, Chorus-Ensemble, Phaser-Flanger, Redux or Channel EQ.

Anything else

Resample it: record one long held C3 into audio, export it as a WAV, AirDrop it to Note and load it into a Melodic Sampler track.

You don't need the hidden Options.txt setting or the right-click export. This page reads the rack file directly and writes the same file Live's own export writes.

Runs entirely in your browser; nothing is uploaded. Labels for some rarely-used Drift settings (LFO shapes beyond Sine, unison voice modes) come from Live's menu order and are marked in the details.
